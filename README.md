# LinguaSpace

### Discover Languages. Explore Worlds.
LinguaSpace is a language learning and cultural discovery website designed to make language learning more engaging and enjoyable.

## Features

- Explore different languages.
- Discover cultures and traditions from around the world.
- Search for countries.
- Read inspirational quotes.
- Enjoy a modern and responsive user interface.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Git and GitHub

## Languages

- English
- Italian
- French
- Persian

## Project Goal

Our goal is to make language learning more interactive by connecting languages with culture, inspiration, and discovery.
